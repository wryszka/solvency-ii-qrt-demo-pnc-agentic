# Standards pointer

This demo is built and reviewed against the **Bricksurance demo standard**. The
standard lives in **one canonical location** — this repo does **not** copy it.

- **Canonical standard:** [`wryszka/bricksurance-playbook`](https://github.com/wryszka/bricksurance-playbook) → `BUILD_AND_REVIEW.md`
  (the build method + §6 review scorecard + §7 review panel), with `DESIGN_LANGUAGE.md`
  and `MANIFESTO.md` alongside.
- **Standard version last reviewed against:** **2.2 — 2026-08-26**
- **Last review of this demo:** 2026-08-26 — see [`docs/REVIEW/REVIEW_REPORT.md`](docs/REVIEW/REVIEW_REPORT.md)
  (8-agent fan-out panel) and the fixes logged in [`DECISIONS.md`](DECISIONS.md).

Deviations from the standard (e.g. the Tailwind + pillar-palette design language)
are justified in `DECISIONS.md`, per the standard's "deviations must be justified"
rule — the demo mirrors the house system, it doesn't copy the standard doc.
